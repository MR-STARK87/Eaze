Introduction

Eaze is a beginner-friendly, English-like programming language designed to make coding accessible to everyone. By replacing cryptic symbols with intuitive keywords, Eaze lets you focus on logic rather than syntax.

Philosophy: Eaze prioritizes readability and simplicity. "set x to 5" is easier to understand than "int x = 5;" for someone starting their journey.

Why Eaze?

  • English-like Syntax: Uses natural language patterns (set, show, ask, repeat).
  • Unified Assignment: No more confusion between = and == for beginners.
  • AI Powered: Built-in support for code explanation, debugging, and conversion to JavaScript.
  • Minimal Friction: No boilerplate code required to get started.

A Quick Taste

# This is an Eaze program
set name to "Explorer"
show "Hello, " + name

repeat 3 times
  show "Learning Eaze is fun!"
end

Setup & Usage

Eaze runs on Node.js and includes both a Command Line Interface (CLI) and a Web Playground.

Installation

Clone the repository and install dependencies:

git clone https://github.com/your-repo/eaze.git
cd eaze
npm install

Running the REPL

Start an interactive session where you can type Eaze code line by line:

npm start

Running a File

Execute an Eaze script file (usually with a .eaze extension):

node cli/index.js examples/fibonacci.eaze

Web Playground

Open Eaze Playground/kids_code_editor_v5.html in any modern browser to use the visual editor with AI integration.

Variables & Syntax

In Eaze, variables are containers for storing data values. You don't need to declare types (like int or string)—Eaze figures it out for you.

Variable Assignment

Use the set ... to ... syntax to create or update variables.

set score to 100
set player to "Alice"
set is_winner to 1  # 1 is true, 0 is false

Reassignment

You can change the value of a variable at any time.

set x to 5
set x to x + 10
show x  # Output: 15

Comments

Use the # symbol to add notes to your code. Everything after # on that line will be ignored by the computer.

Data Types

Eaze supports three main types of data:

1. Numbers

Includes both whole numbers (integers) and decimals (floating-point).

set age to 25
set price to 19.99
set negative to -10

2. Strings

Text values enclosed in single (') or double (") quotes.

set greeting to "Hello World"
set name to 'Eaze'

3. Arrays

Ordered lists of values. Arrays are zero-indexed, meaning the first item is at position 0.

set fruits to ["Apple", "Banana", "Cherry"]
show fruits[0]  # Output: Apple

Logical

Eaze uses English keywords for logic:

  • and: True if both sides are true.
  • or: True if at least one side is true.
  • not: Flips the truth value.

Input & Output

Output: show

Displays a value to the screen.

show "Hello"
show 42
show 5 + 5

Input: ask ... into

Asks the user a question and stores their answer in a variable.

ask "What is your name?" into user_name
show "Welcome, " + user_name
Note: Eaze automatically tries to convert input to a number if it looks like one.

Conditionals

Conditionals allow your program to make decisions.

If Statement

if age >= 18
  show "You are an adult."
end

If-Else Statement

if score >= 50
  show "You passed!"
else
  show "Try again."
end

Loops

Loops allow you to run the same code multiple times.

Repeat Loop

Use this when you know exactly how many times you want to repeat.

repeat 5 times
  show "Counting..."
end

While Loop

Use this to repeat code as long as a condition is true.

set count to 1
while count <= 5
  show count
  set count to count + 1
end

Functions

Functions are reusable blocks of code. You define them once and "call" them whenever you need them.

Defining a Function

define greet(name)
  show "Hello, " + name
end

Calling a Function

Use the call keyword followed by the function name.

call greet("Alice")
call greet("Bob")

Returning Values

Functions can send a value back to where they were called.

define square(n)
  return n * n
end

set result to call square(4)
show result  # Output: 16

Arrays

Arrays are powerful tools for managing lists of data.

Creating Arrays

set numbers to [10, 20, 30]
set mixed to [1, "hello", [1, 2]]

Accessing and Modifying

set items to ["A", "B", "C"]
show items[1]  # Output: B

set items[0] to "Z"
show items  # Output: ["Z", "B", "C"]

AI Integration

Eaze is designed for the modern world, featuring built-in AI assistant capabilities to help you learn faster.

Code Explanation

The Eaze playground can explain what any piece of code does in plain English. It analyzes the structure of your code and generates a step-by-step walkthrough.

Intelligent Debugging

Instead of cryptic error messages, Eaze's AI can analyze your errors and suggest specific fixes, teaching you the right way to code as you go.

JavaScript Conversion

Ready to level up? Eaze can automatically convert your programs into standard JavaScript, helping you bridge the gap between educational coding and professional development.

Sample Programs

Fibonacci Generator

# Generate the first N Fibonacci numbers
ask "How many numbers?" into n
set a to 0
set b to 1

repeat n times
  show a
  set temp to a + b
  set a to b
  set b to temp
end

Guessing Game

set secret to 42
set found to 0

while found == 0
  ask "Guess my number:" into guess
  if guess == secret
    show "Correct!"
    set found to 1
  else
    if guess < secret
      show "Higher..."
    else
      show "Lower..."
    end
  end
end
